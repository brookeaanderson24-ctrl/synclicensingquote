      How this works

      What this tool is

      Sync Quote Request collects the details a music publisher needs before quoting a synchronization (sync) license. It organizes them into a one-page summary that you can download as a PDF and send to the publisher.

      It runs entirely in your browser. There is no account, no database and no music catalog lookup. Everything on the page comes from what you type.

      What it does not do

      • It never calculates, estimates or suggests a license fee.
      • It never assumes that rights are cleared or that a request will be approved.
      • It does not cover master use. That license is requested separately from the recording owner.
      • It does not send anything, and it does not look up songs, artists or publishers.

      How to use it

      1. Fill in the form. The one-page sheet updates as you type.
      2. Check the "Items for publisher to confirm" list and fill any gaps you can.
      3. Select Download PDF once every required field is complete.
      4. Send the PDF to the publisher from your own email. This tool cannot send or attach files.

      Load example fills the form with fictional entries so you can see how it works. Clear form removes everything you entered.

      The rules, in full

      Every message below is the exact wording the app uses. These tables are generated from the same list the app checks, so the two cannot disagree. Errors block the PDF. Warnings do not, and they print in the "Items for publisher to confirm" box. Notes appear on screen only.

      No rule compares a budget to a typical or market rate, predicts whether a request will be approved, or infers who owns or has cleared any rights.

      Your data

      What you type stays in your browser. Nothing is sent to a server and nothing is saved. Closing or refreshing the page clears the form.

      When the page opens, it loads one PDF library from a public content delivery network (cdnjs.cloudflare.com). Your entries are not sent there.

      Known limitations

      • The PDF supports Latin letters and accents only. Other scripts print as "?", and the app warns you when that happens.
      • The PDF is always one page, so the project description and scene description are limited to 300 characters each.
      • The tool cannot attach the PDF to an email. You attach it yourself.
      • The only rule based on a number is C4, which asks the publisher to confirm any duration over 300 seconds.
      • The Download PDF button needs the PDF library to load, so the page needs an internet connection when it opens.

      Last updated November 12, 2026.
